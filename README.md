# 📚 Student Book Management System

## Description
This is a beginner-friendly Python project that demonstrates the basic concepts of Object-Oriented Programming (OOP).

## Features
- Store and display a person's information
- Create a student using inheritance
- Store book details using encapsulation
- Display book information using class methods

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Encapsulation
- Constructors (`__init__`)
- Methods
- `super()`

## Project Structure

```
Student-Book-Management/
├── student_book.py
└── README.md
```

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the following command:

```bash
python student_book.py
```
